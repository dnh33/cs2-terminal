Password Hasher

Generate the AUTH_PASSWORD_HASH and AUTH_SESSION_SECRET values for your CS2 Terminal worker.

Everything happens in this browser tab. Nothing is sent over the network. Open the page from your local filesystem (or hosted somewhere you trust) and don't paste your password into any other site.

strength: —
Store these as secrets on your Cloudflare Worker (Settings → Variables and Secrets → Add → Type: Secret). Once stored, you cannot read them back from the dashboard — and that's the point. Save the password in your password manager. Discard this tab.
  1. Open your worker in the Cloudflare dashboard.
  2. Settings → Variables and Secrets.
  3. Add a secret named AUTH_PASSWORD_HASH with the first value above.
  4. Add a secret named AUTH_SESSION_SECRET with the second value above.
  5. Click Save and deploy.
  6. Visit your frontend — it will now require login.
